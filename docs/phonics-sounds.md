# Phonics Sounds — Recording List (44 sounds)

Record each sound and save it with the **file name** shown.

**Where the files go:** `app/src/main/assets/audio/phonics/`. That folder already has
44 empty placeholder files with these exact names. Replace each empty file with your
recording (same name). `.m4a`, `.mp3` or `.wav` all work. If you use a different
extension, delete the empty `.m4a` with the same name.

Until a sound is recorded, the app skips it and just says the example word instead.
Claude Code can also trim silence and even out volume for you later.

## How to record (important)

1. Quiet room, fan off, phone 15–20 cm from your mouth. Any voice-recorder app is fine.
2. Say **only the sound**, short and clear. Not the letter name.
   - ✅ /b/ = a short "b" puff — ❌ not "bee", ❌ not "buh" (no extra "uh" at the end)
   - ✅ /s/ = "ssss" — ❌ not "es"
3. Each file should contain **only the sound, once** (about 0.5–1 second). The app plays it,
   then says the example word itself. Record a few tries and keep the best one.
4. Long sounds (s, f, m, n, sh, v, z, l) can be stretched for 1 second: "sss", "mmm".
5. Same voice for all 44 sounds, same distance, same room.
6. Any format is fine (m4a, mp3, wav).

Hindi hints are only a guide for *you* while recording — some English sounds have no exact Hindi match.

## Backup option (if you don't want to record)

Wikimedia Commons has free recordings of individual speech sounds (mostly
CC BY-SA licence, which means we must show credits in the app). They are made by
language experts, so they sound less child-friendly and don't match all 44
English sounds exactly, especially the long vowels (eɪ, aɪ, əʊ…). Recording
yourself gives better, consistent results.
